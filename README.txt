RAMADAN STORY TIME – how to put it online (free, no login for students)

FILES: index.html (students) | admin.html (your editor) | stories.json (the stories) | style.css

1. Go to https://app.netlify.com/drop and drag this whole folder onto the page.
   (Or use GitHub Pages / Cloudflare Pages / your university web space.)
2. You get a public link like https://something.netlify.app  -> turn it into a QR code.
3. Write stories: open YOUR-LINK/admin.html, add stories, press "Download stories.json".
4. Update the site: replace stories.json on the host (Netlify: drag the folder onto the site's Deploys page again).
5. Tip: rename admin.html to something hard to guess (e.g. editor-x7k2.html). Students never see a link to it, and it cannot change the live site by itself.
6. Test on a phone before printing posters. Use YOUR-LINK/?preview=1 to see all days open.

Notes: the app must be opened over https (a hosted link), not by double-clicking index.html.
Student progress is stored on their own phone/browser.
